# 00. 데이터 품질·무결성 보고서

## 1. 목적

본 단계의 목적은 IEEE-CIS Fraud Detection 원본 데이터가 이후의 탐색, 모델링 및 정책 비교에
사용될 수 있는지 확인하는 것이다. 구체적으로 원본 파일의 구성, 거래·신원 데이터의 병합,
식별자 무결성, 타깃 분포, 거래금액 범위, 시간 순서와 결측 구조를 점검하였다.

## 2. 데이터 구성과 병합

원본 데이터는 거래 정보와 신원 정보로 나뉜다. `train_transaction.csv`와
`train_identity.csv`, `test_transaction.csv`와 `test_identity.csv`를 각각
`TransactionID` 기준으로 left join하였다. 모든 거래에 신원 정보가 존재하지 않으므로 inner
join을 사용하면 다수의 거래가 제거된다. 따라서 거래 데이터를 기준으로 행을 보존하고, 신원
정보가 없는 경우는 결측으로 유지하였다.

반복적인 CSV 파싱 비용을 줄이기 위해 수치형 dtype을 축소한 뒤 Parquet 형식으로 저장하였다.
처리된 학습 데이터의 메모리 사용량은 약 0.98GB이다.

## 3. 기본 무결성 결과

| 점검 항목 | 결과 |
|---|---:|
| 학습 데이터 | 590,540행 × 434열 |
| 공식 test 데이터 | 506,691행 × 433열 |
| 학습 데이터 TransactionID 중복 | 0건 |
| test 데이터 TransactionID 중복 | 0건 |
| train/test TransactionID 교집합 | 0건 |
| 사기 거래 | 20,663건 |
| 사기율 | 3.499% |
| 거래금액 결측 | 0건 |
| 최소 거래금액 | 0.25 USD |
| 최대 거래금액 | 31,937.39 USD |

식별자 중복이나 train/test 간 식별자 중첩은 발견되지 않았다. 타깃은 약 3.5%만 사기인 불균형
구조이므로 정확도만으로 모델을 평가하는 것은 적절하지 않다. 이후 모델 평가에서는 PR-AUC와
상위 위험 거래의 정밀도·재현율을 함께 사용한다.

## 4. 시간 범위

`TransactionDT`는 실제 날짜가 아니라 비공개 기준 시점으로부터의 경과 초이다. 학습 데이터는
약 182일, 공식 test 데이터는 약 183일을 포함하며 두 구간 사이에는 약 30일의 간격이 있다.

| 구간 | TransactionDT 범위 | 포함 기간 |
|---|---:|---:|
| train | 86,400–15,811,131 | 약 182일 |
| test | 18,403,224–34,214,345 | 약 183일 |

공식 test가 학습 데이터보다 뒤 시점에 위치하므로 실제 적용 상황도 과거 거래로 학습해 미래
거래를 평가하는 형태에 가깝다. 이에 따라 이후 검증은 무작위 분할이 아니라 시간 순서를 보존한
분할을 기본으로 사용한다.

## 5. 변수군과 결측 구조

학습 데이터에는 `V1~V339` 339개, `id_01~id_38` 38개, `D1~D15` 15개,
`C1~C14` 14개를 포함한 총 434개 변수가 존재한다. 결측이 전혀 없는 변수는 20개이며,
결측률이 90%를 넘는 변수는 12개이다. 특히 일부 신원 변수는 결측률이 약 99%에 달한다.

이 결측을 단순한 데이터 오류로 간주해서는 안 된다. 신원 정보는 모든 거래에서 수집되지
않으며, 결측 여부 자체가 거래 채널이나 정보 수집 경로를 반영할 수 있기 때문이다. 따라서
고결측 변수를 일괄 삭제하거나 평균으로 대치하기보다, 결측을 직접 처리할 수 있는 모델을
사용하고 결측 패턴의 정보성을 별도로 확인한다.

## 6. 평가 범위

공식 test 데이터에는 `isFraud` 레이블이 없다. 따라서 공식 test는 시간 구조와 스키마를
확인하는 데만 사용하며, 모델 성능과 정책 비용은 레이블이 있는 학습 데이터를 시간 순서대로
train, calibration, internal test로 다시 나누어 평가한다.

## 7. 결론

590,540건의 학습 거래가 정상적으로 병합되었고 식별자 중복, train/test 중첩, 거래금액 결측은
발견되지 않았다. 데이터는 이후 분석에 사용할 수 있지만, 강한 클래스 불균형과 대규모 구조적
결측, 명확한 시간 순서를 함께 고려해야 한다. 이 결과를 바탕으로 다음 단계에서는 시간에 따른
사기율 변화와 결측 블록, 주요 세그먼트의 분포를 탐색한다.
