# 최종 보고서: IEEE-CIS 사기 탐지 모델 및 정책 비교

## 1. 개요와 문제 정의

본 프로젝트는 IEEE-CIS Fraud Detection 데이터를 사용해 (1) 시간에 따른 미래 거래를
예측하는 사기 확률 모델을 구축하고, (2) 그 확률을 기반으로 승인·차단·검토·인증을
조합한 운영 정책을 비교해 총비용을 낮추는 것을 목표로 한다.

전체 작업은 00~07 여덟 개 단계 보고서로 구성되며, 본 문서는 그 결과를 통합하고
최종적으로 검증된 결론과 아직 검증되지 않은 가설을 구분해 정리한다.

```text
00 데이터 품질 → 01 구조 탐색 → 02 비용 관점 EDA → 03 검증 설계
  → 04 피처 설계 → 05 모델·보정 → 06 정책 비교 → 07 추가 검증(UID/가중치)
```

## 2. 데이터와 검증 설계

- 학습 데이터는 590,540건, 사기율 3.499%의 불균형 데이터다. 식별자 중복이나
  train/test 교집합은 없다([00](00_data_check.md)).
- `TransactionDT`는 실제 날짜가 아닌 경과 초이며, 공식 test가 학습 데이터보다 미래
  시점에 위치한다. 사기율은 일별 1.10~6.99%로 변동하고 상품·기기·카드 세그먼트별
  차이도 크다([01](01_eda_overview.md)).
- 무작위 분할은 시간 기반 분할보다 PR-AUC를 0.2317 높게 낙관화한다. 이에 따라 전
  단계에서 시간 순서를 보존한 분할(train 65% / calibration 15% / internal test 20%)을
  사용하고, 모델 학습·보정법 선택·정책 선택·시간 안정성 확인에 서로 다른 구간을
  배정했다([03](03_validation_design.md)).
- 사기 손실은 상위 금액 거래에 강하게 집중된다(상위 20% 거래가 손실의 62.9%). 다만
  세그먼트별 사기율 순위와 손실 비중 순위는 서로 다르다(예: ProductCD C는 사기율
  최고이나 손실 비중은 12.7%에 불과, W는 사기율 최저이나 손실 비중 66.6%)([02](02_eda_cost_relevant.md)).

## 3. 피처와 모델

- 명시적 고객 ID가 없어 `card1`+`addr1`+추정 계정일로 휴리스틱 UID를 구성했다
  (추정 성공률 88.7%). 시점 누수를 막기 위해 모든 집계·빈도 통계는 train 구간에서만
  학습해 이후 구간에 고정 적용했다([04](04_features.md)).
- 주 모델은 비가중 LightGBM이며, internal test에서 가중 모델과 로지스틱 회귀
  기준선보다 변별력(PR-AUC 0.5166)과 보정 오차 모두 우수했다([05](05_model.md)).
- Calibration 단계에서는 사전 기준(Brier score 최저)에 따라 Isotonic 보정을
  선택했으나, internal test에서는 Raw 확률이 PR-AUC·Brier score 모두 근소하게
  더 우수했다. 이는 calibration 구간과 미래 구간의 기초 사기율 차이(3.92% vs 3.44%)에
  따른 보정 불안정성으로 해석되며, 사후 교체는 하지 않고 Isotonic을 정책 분석에
  고정 사용했다.
- UID 피처는 기존 internal test에서 PR-AUC를 0.0045 개선했지만, 07 단계의 train
  내부 4-fold 교차검증에서는 4개 중 2개 fold에서만 개선되고 평균은 오히려 UID 제외가
  근소하게 우수했다(0.601050 vs 0.599438). 따라서 UID의 최종 채택 근거는
  불충분하며, 탐색용 보조 피처로만 남긴다([07](07_model_validation.md)).

## 4. 정책 비교

- 단순 금액 규칙(P1)은 오차단이 급증해 무개입(P0)보다 비용이 22.02% 높았다.
  모델 확률을 사용하는 것만으로(P2) 비용을 34.09% 절감할 수 있었다.
- 검토·인증이 불가능한 조건에서는 거래금액별 임계값을 쓰는 P4가 두 시간 구간
  모두에서 최저비용이었으나, P3 대비 개선폭은 작고(선택용 0.12%) bootstrap
  신뢰구간이 0을 포함해 통계적으로 확정할 수 없었다.
- 소규모 사람 검토(P5, 일 27건)는 P4 대비 10.78% 추가 절감, 추가 인증까지 포함한
  P6은 P5 대비 40.02% 추가 절감을 보였다. 두 시간 구간(선택용/확인용) 모두에서
  정책 순위(P4 최저 in 무검토, P6 최저 in 전체)가 재현됐다([06](06_policy_comparison.md)).
- 민감도 분석 결과 정상 오차단 페널티가 30~60 구간이면 P2·P3이 P4보다 우수해질 수
  있고, 인증 마찰 비용이 20을 넘으면 P5가 P6보다 유리해진다. 즉 P6의 우위는 관측되지
  않은 인증 성능·비용 가정에 의존적이다.
- 세그먼트별 고객 영향에서는 `card4=discover` 집단의 정상 거래 기대 거절률(6.90%)이
  `card4=visa`(1.75%)보다 뚜렷이 높아, 정책 확장 전 집단별 영향 점검이 필요하다.

## 5. 최종 결론

1. **모델**: 비가중 LightGBM + Isotonic 보정을 현재 최선의 확률 모델로 채택하되,
   보정법의 미래 안정성이 낮으므로 재학습 시마다 보정을 재검증해야 한다. UID
   피처는 확정 채택 근거가 부족해 다음 실험에서는 제외 버전을 우선 비교한다.
2. **정책**: 검토·인증 없이 운영해야 한다면 P4(또는 근접한 P3)를 시작점으로 삼는다.
   소규모 사람 검토가 가능하면 P5, 추가 인증 파일럿이 가능하면 P6까지 단계적으로
   확장하는 조건부 도입을 권고한다. P6의 전면 도입은 실제 인증 통과율·비용 데이터
   없이는 정당화되지 않는다.
3. **검증의 한계**: 모든 성능·비용 수치는 동일한 internal test를 반복 확인하며
   얻은 결과이므로 완전히 독립적인 평가가 아니다. 실제 배포 전에는 더 최신의
   별도 데이터로 모델·보정·정책을 재검증해야 한다.

## 6. 향후 과제

- UID 제외를 기본으로 하는 재학습 및 하이퍼파라미터의 체계적 시간 CV 탐색
- 인증 통과율·검토 포착률의 실측 데이터 수집 후 P6 비용 재평가
- 실시간 검토/인증 할당 방식(선착순 대비 일괄)의 온라인 정책 설계
- 세그먼트별(카드 브랜드·기기 유형) 공정성 지표를 실제 운영 로그로 검증
- 보정법의 정기 재학습 체계 및 고액 거래 구간 모니터링 구축
